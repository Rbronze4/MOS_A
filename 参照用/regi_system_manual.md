# みどり亭 レジシステム 操作マニュアル

## 1. はじめに

本マニュアルは、みどり亭レジシステムを初めて利用する店舗スタッフおよび管理者向けに、基本的な操作方法を説明するものです。

本システムでは、モバイルオーダーシステムから取得した注文の会計、手動会計、割引、分割会計、会計履歴の確認、レシート・領収書の再発行、売上レポート、レジ締め、店舗・アカウントの管理などを行うことができます。

---

## 2. 対象者

本マニュアルは、次の利用者を対象としています。

* 店舗スタッフ
* レジ担当者
* マスターアカウントを使用する管理者

---

## 3. システムでできること

| 機能     | 内容                         |
| ------ | -------------------------- |
| ログイン   | 登録済みのログインIDとパスワードでログインする   |
| 会計入力   | 客番号入力、注文検索、手動金額入力から会計を開始する |
| 注文確認   | 注文商品、数量、単価、税額、合計金額を確認する    |
| 割引     | 円引きまたは％割引を適用する             |
| 通常会計   | 現金、カード、電子マネーで決済する          |
| 分割会計   | 人数分割、金額分割、商品別分割を行う         |
| 会計履歴   | 過去の会計内容を検索・確認する            |
| 帳票再発行  | レシートまたは領収書を再発行する           |
| 売上レポート | 日次・週次・月次の売上を確認する           |
| レジ締め   | 売上とレジ内の現金を照合する             |
| 設定     | 店舗、アカウント、バックアップなどを管理する     |

## 4. 環境構築

### 4.1 XAMPPをインストールする

次のWebサイトから、Windows版のXAMPPをダウンロードします。

https://www.apachefriends.org/jp/download.html

ダウンロードしたインストーラーを起動し、画面の案内に従ってインストールします。

インストール先は、特別な理由がない限り、次の場所を使用してください。

```text
C:\xampp
```

インストール中にWindowsのセキュリティ警告が表示された場合は、Apacheの通信を許可してください。

---

### 4.2 XAMPPを起動する

XAMPPのインストールが完了したら、**setup_xampp**を起動します。
それが終わったら、**XAMPP Control Panel**を起動します。

次の項目の**Start**ボタンを押してください。

* Apache
* MySQL

正常に起動すると、ApacheとMySQLの項目が緑色で表示されます。

終了するときは、それぞれの**Stop**ボタンを押します。

### 4.3 プロジェクトを配置する

レジシステムのプロジェクトフォルダーを、XAMPPの`htdocs`フォルダー内に配置します。

配置後、主なフォルダーとファイルが次のようになっていることを確認してください。

```text
C:\xampp\htdocs\regi
├─ database
├─ public
│  ├─ index.php
│  ├─ .htaccess
│  └─ assets
├─ src
│  ├─ Controllers
│  ├─ Database
│  ├─ Repositories
│  ├─ Routes
│  ├─ Services
│  ├─ Infra

├─ tests
└─ storage
```

プロジェクトフォルダーの名称を変更した場合は、ブラウザで使用するURLやシステム内のパス設定も変更する必要があります。

XAMPP Control PanelでApacheとMySQLを起動した状態で、MySQLの**Admin**ボタンを押します。

ブラウザでphpMyAdminが表示されます。

画面左側または上部の**新規作成**を選択し、次の内容を入力します。

| 項目      | 入力内容               |
| ------- | ------------------ |
| データベース名 | regi_system       |
| 照合順序    | utf8mb4_unicode_ci |

入力後、**作成**ボタンを押します。

データベース一覧に`regi_system`が表示されれば、作成完了です。

6. 画面下部の**インポート**または**実行**を押す

インポート完了後、画面左側にテーブルが表示されることを確認してください。

```text

bill

bill_payment
register_closing

yearly_sales_summary
```

### 4.6 データベースの接続情報を設定する

レジシステムからMySQLへ接続するため、データベース接続設定を確認します。

接続設定が記述されているファイルを開きます。

例：

```text
C:\xampp\htdocs\regi\src\Database\db.php
```

設定例は次のとおりです。

```php
<?php

    'host' => 'localhost',
    'port' => '3306',

    'username' => 'root',
    'password' => '',

```

| 項目      | 設定値          |
| ------- | ------------ |
| ホスト名    | localhost    |
| ポート番号   | 3306         |
| データベース名 | regi_system |
| ユーザー名   | root         |
| パスワード   | 空欄           |
| 文字コード   | utf8mb4      |

利用する環境によって設定が異なる場合は、管理者から指定された情報を入力してください。

```text
C:\xampp\htdocs\regi\src\Config\mos.php
```

以下のコードから任意のパスを指定してください。
```php

```

### 4.10 MOS APIの接続URLについて

レジシステムでは、`mos.php`に設定した`base_url`の後ろに、次のパスを追加して通信します。

```text
/api/orders
```

例えば、次のように設定した場合、

```php
'base_url' => 'http://192.168.0.123/MOS/example',
```

実際の接続先は次のURLになります。

```text
http://192.168.0.123/MOS/example/api/orders
```

`base_url`には、`/api/orders`を含めないでください。

誤った設定例：

```php
'base_url' =>
    'http://192.168.0.123/MOS/example/api/orders',
```

このように設定すると、接続先が次のように重複する可能性があります。

```text
http://192.168.0.123/MOS/example/api/orders/api/orders
```

## 6. 会計入力画面

会計入力画面では、会計する注文を指定します。

会計を開始する方法は、次の3種類です。

1. 客番号入力
2. 注文選択
3. 手動金額入力

---

## 7. 客番号を入力して会計する

### 7.1 客番号を入力する

**客番号入力**では、モバイルオーダーシステムで発行された7桁の客番号を入力します。

入力方法は次の2種類です。

* バーコードを読み取る
* 画面上のテンキーを使用する

入力例：

```text
0000123
```

客番号は、先頭の「0」を含めて7桁で入力してください。

### 7.2 エラーが表示される場合

| 原因           | 対処方法               |
| ------------ | ------------------ |
| 客番号が7桁ではない   | 7桁の数字を入力する         |
| 該当する注文がない    | 客番号を確認する           |
| 注文がすでに会計済み   | 会計履歴を確認する          |
| MOSとの通信に失敗した | 時間をおいて再度検索する       |
| システムエラーが発生した | エラー内容を記録して管理者へ連絡する |

---

## 8. 注文を検索して会計する

注文選択では、検索条件を指定し、一覧から会計対象の注文を選択できます。

### 8.1 検索条件

主な検索条件は次のとおりです。

| 条件   | 内容                  |
| ---- | ------------------- |
| 会計状態 | 受付中、会計中、未収金などから選択する |
| 店舗   | 対象店舗を指定する           |
| 開始日時 | 検索対象の開始日時を指定する      |
| 終了日時 | 検索対象の終了日時を指定する      |

### 8.2 注文を検索する

1. 必要な検索条件を入力する
2. **検索**ボタンを押す
3. 条件に一致した注文を確認する
4. 会計する注文を選択する

検索条件を指定しすぎると注文が見つからない場合があります。その場合は、条件を減らして再検索してください。

---

## 9. 手動金額入力で会計する

手動金額入力では、モバイルオーダーシステムを使用していない注文や、臨時の商品を会計できます。

### 9.1 商品情報を入力する

次の内容を入力します。

* 数量
* 単価または金額
* 税率

### 9.2 入力時の注意

* 数量が正しいか確認してください
* 会計に進む前に合計金額を確認してください

### 9.3 会計へ進む

入力内容に問題がなければ、会計へ進むボタンを押します。

---

## 10. 注文一覧画面

注文一覧画面では、会計前の注文内容を確認します。

### 10.1 確認する内容

| 項目  | 内容            |
| --- | ------------- |
| 客番号 | 注文に紐づく7桁の番号   |
| 商品名 | 注文された商品名      |
| 数量  | 商品ごとの注文数量     |
| 単価  | 商品1個あたりの金額    |
| 金額  | 数量を含めた商品ごとの金額 |
| 小計  | 割引前の金額        |
| 割引  | 適用されている割引額    |
| 消費税 | 会計に含まれる税額     |
| 合計  | 実際に支払う税込金額    |

### 10.2 複数の客番号をまとめる

同じ会計に複数の注文をまとめる場合は、客番号を追加できます。

例：

```text
0000001
0000002
0000003
```

追加した客番号の商品は、同じ注文一覧にまとめて表示されます。

複数の注文をまとめる場合は、別のお客様の注文を誤って追加していないか、客番号・商品・合計金額を必ず確認してください。

### 10.3 会計方法を選択する

注文内容を確認した後、次のいずれかを選択します。

* 割引を適用する
* 通常会計へ進む
* 分割会計へ進む

---

## 11. 割引を適用する

会計前に、円引きまたは％割引を適用できます。

### 11.1 割引方法

| 割引方法 | 内容                  |
| ---- | ------------------- |
| 円引き  | 入力した金額を合計金額から差し引く   |
| ％割引  | 入力した割合に応じて合計金額を割り引く |

### 11.2 円引きの例

```text
500円引き
```

### 11.3 ％割引の例

```text
10％割引
```

### 11.4 割引時の注意

* 円引きと％割引は同時に適用できません
* 割引額が会計金額を超えないようにしてください
* 割引を適用した後は、変更後の合計金額を確認してください
* 入力を間違えた場合は、割引を解除または再入力してください

---

## 12. 通常会計

通常会計では、支払い方法を選択して決済します。

### 12.1 支払い方法

| 支払い方法 | 内容                  |
| ----- | ------------------- |
| 現金    | 受領金額を入力し、お釣りを計算する   |
| カード   | カードで支払ったものとして会計する   |
| 電子マネー | 電子マネーで支払ったものとして会計する |

---

## 13. 現金で会計する

### 13.1 現金を選択する

支払い方法から**現金**を選択します。

### 13.2 受領金額を入力する

お客様から受け取った金額を入力します。

例：

```text
合計金額：2,750円
受領金額：3,000円
お釣り：250円
```

受領金額を入力すると、お釣りが自動計算されます。

### 13.3 ちょうど支払いの場合

合計金額と同じ金額を受け取った場合は、**ちょうど**ボタンを押します。

受領金額に、合計金額と同じ金額が自動入力されます。

### 13.4 決済を完了する

次の内容を確認します。

* 合計金額
* 受領金額
* お釣り

問題がなければ、**決済完了**ボタンを押します。

受領金額が合計金額より少ない場合は、決済できません。

---

## 14. カード・電子マネーで会計する

### 14.1 支払い方法を選択する

支払い方法から、**カード**または**電子マネー**を選択します。

### 14.2 金額を確認する

カード・電子マネーでは、現金の受領金額やお釣りは入力しません。

決済端末などで支払いが完了していることを確認し、画面に表示された合計金額を確認してください。

### 14.3 決済を完了する

問題がなければ、**決済完了**ボタンを押します。

実際のカード・電子マネー決済が完了する前に、レジシステム側の決済を完了しないでください。

---

## 15. 分割会計

分割会計では、1つの注文を複数回の支払いに分けることができます。

利用できる分割方法は次の3種類です。

| 分割方法  | 内容               |
| ----- | ---------------- |
| 人数分割  | 合計金額を指定した人数で分割する |
| 金額分割  | 支払う金額を任意に指定する    |
| 商品別分割 | 支払う商品を選択する       |

### 15.1 分割会計の重要な注意事項

分割会計で1回目の支払いを完了した後は、次の変更はできません。

* 通常会計への変更
* 別の分割方法への変更
* 分割会計の最初からのやり直し

分割方法は、最初の支払いを実行する前に必ず確認してください。

途中で画面を閉じた場合や会計を中断した場合でも、支払い済みの情報は保持されます。再度注文を取得すると、残額や支払い済み商品を確認して会計を再開できます。

---

## 16. 人数分割

### 16.1 人数を入力する

1. 分割方法から**人数分割**を選択する
2. 支払い人数を入力する
3. 1人あたりの支払額を確認する

### 16.2 端数の扱い

合計金額が人数で割り切れない場合、端数を含む金額が一部の支払いに加算されます。

例：

```text
合計金額：10,001円
人数：3人

1人目：3,335円
2人目：3,333円
3人目：3,333円
```

画面に表示された各回の支払金額を確認してください。

### 16.3 支払いを進める

1. 今回の支払金額を確認する
2. 支払い方法を選択する
3. 決済を完了する
4. 次の人の支払いに進む
5. 残額が0円になるまで繰り返す

---

## 17. 金額分割

### 17.1 支払金額を入力する

金額分割では、今回支払う金額を任意に入力できます。

例：

```text
合計金額：8,000円

1回目：3,000円
2回目：5,000円
```

### 17.2 残額ちょうど

残っている金額をすべて支払う場合は、**残額ちょうど**ボタンを押します。

今回の支払金額に残額が自動入力されます。

### 17.3 現金で支払う場合

現金を選択した場合は、今回の支払金額とは別に、お客様から受け取った受領金額を入力します。

例：

```text
今回の支払金額：3,000円
受領金額：5,000円
お釣り：2,000円
```

支払金額と同じ金額を受け取った場合は、画面の案内に従って、受領金額を省略するか、ちょうどの金額を入力してください。

### 17.4 残額を確認する

支払い完了後は、次の内容を確認してください。

* 支払い済み金額
* 今回の支払金額
* 残りの金額

---

## 18. 商品別分割

### 18.1 商品を選択する

商品別分割では、今回支払う商品を一覧から選択します。

商品の数量が複数ある場合は、支払う数量を指定します。

選択した商品と数量に応じて、今回の支払金額が計算されます。

### 18.2 支払いを行う

1. 支払う商品を選択する
2. 商品または数量に間違いがないか確認する
3. 今回の支払金額を確認する
4. 支払い方法を選択する
5. 決済を完了する

### 18.3 支払い済み商品の表示

支払いが完了した商品は、商品一覧から削除されず、グレーで表示されます。

これにより、次の内容を確認できます。

* すでに支払いが完了している商品
* まだ支払いが完了していない商品
* 商品ごとの支払い済み数量

支払い済みの商品を重複して選択しないようにしてください。

## 23. レジ締め

レジ締めは、営業終了時に売上とレジ内の現金を確認するための操作です。

### 23.1 レジ締め画面を開く

ホーム画面から**レジ締め**を選択します。

### 23.2 基本情報を確認する

画面に表示された次の内容を確認します。

| 項目      | 内容               |
| ------- | ---------------- |
| 営業日     | レジ締めの対象日         |
| 担当者     | レジ締めを行うスタッフ      |
| 開始時金額   | 営業開始時にレジへ入っていた金額 |
| 売上合計    | 対象期間の売上合計        |
| 現金売上    | 現金支払いの合計         |
| カード売上   | カード支払いの合計        |
| 電子マネー売上 | 電子マネー支払いの合計      |
| 想定現金    | レジ内にあるべき現金額      |
| 実際の現金   | 金種入力から計算された金額    |
| 差額      | 実際の現金と想定現金との差    |

### 23.3 金種を入力する

レジ内の現金を数え、金種ごとの枚数を入力します。

| 金種       | 入力内容 |
| -------- | ---- |
| 10,000円札 | 枚数   |
| 5,000円札  | 枚数   |
| 1,000円札  | 枚数   |
| 500円玉    | 枚数   |
| 100円玉    | 枚数   |
| 50円玉     | 枚数   |
| 10円玉     | 枚数   |
| 5円玉      | 枚数   |
| 1円玉      | 枚数   |

入力した枚数をもとに、実際の現金額が自動計算されます。

### 23.4 点検を行う

金種を入力したら、点検を実行します。

差額が0円の場合は、想定現金と実際の現金が一致しています。

差額がある場合は、次の内容を確認してください。

* 金種の入力枚数
* 現金の数え間違い
* 受領金額の入力ミス
* お釣りの渡し間違い
* 会計履歴
* 手動会計の入力内容

### 23.5 レジ締め結果を保存する

内容に問題がなければ、レジ締め結果を保存します。

保存後は、営業日、担当者、売上、実際の現金、差額などが記録されます。

## 27. バックアップ管理

バックアップ管理画面では、システムデータのバックアップを作成したり、過去の実行履歴を確認したりできます。

バックアップには、管理者が任意のタイミングで実行する「手動バックアップ」と、システムが自動的に実行する「自動バックアップ」があります。

---

### 27.1 バックアップ履歴の確認

バックアップ管理画面には、これまでに実行されたバックアップの履歴が表示されます。

履歴では、主に次の内容を確認できます。

| 項目       | 内容                            |
| -------- | ----------------------------- |
| バックアップ日時 | バックアップが実行された日時                |
| バックアップ種別 | 手動または自動             |
| 実行結果     | 成功または失敗                       |
| ファイル情報   | 作成されたバックアップファイルの名称や保存情報       |
| メモ       | 手動バックアップ時に入力された内容や、実行結果に関する情報 |

実行結果が「失敗」と表示されている場合は、エラー内容を確認し、必要に応じて管理者または開発担当者へ連絡してください。

---

### 27.2 自動バックアップ

本システムでは、レジ締めが正常に完了した後に、自動バックアップを実行します。

自動バックアップは、原則として1営業日につき1回実行されます。同じ営業日に複数回レジ締めを行った場合でも、すでに自動バックアップが完了している場合は重複して作成されません。

自動バックアップでは、次の内容が登録されます。

| 項目      | 内容        |
| ------- | --------- |
| 種別      | 自動   |
| 実行タイミング | レジ締め完了後   |
| 実行回数    | 1営業日につき1回 |

自動バックアップの実行結果は、バックアップ履歴から確認できます。

自動バックアップが失敗している場合は、必要に応じて手動バックアップを実行し、管理者または開発担当者へ連絡してください。

---

### 27.3 手動バックアップ

自動バックアップとは別に、管理者が任意のタイミングでバックアップを作成できます。

手動バックアップを実行した後は、バックアップ履歴を確認し、実行結果が「成功」になっていることを確認してください。

---

### 27.4 バックアップ実行時の注意

バックアップを安全に管理するため、次の点に注意してください。

* 手動バックアップの処理中は、画面を閉じたり再読み込みしたりしないでください
* バックアップ実行後は、履歴で実行結果が「成功」になっていることを確認してください
* バックアップファイルの名称変更、移動、削除、内容の編集を行わないでください
* バックアップファイルを通常の業務データとして開かないでください
* 実行結果が「失敗」の場合は、繰り返し実行する前にエラー内容を確認してください
* 復元操作は既存データに影響するため、管理者または開発担当者の指示に従ってください

---

### 27.5 バックアップが失敗した場合

バックアップ履歴の実行結果が「失敗」となっている場合は、次の内容を確認してください。

1. XAMPPのApacheとMySQLが正常に起動しているか確認します。
2. バックアップファイルの保存先が存在するか確認します。
3. 保存先にファイルを書き込むための権限があるか確認します。
4. 保存先の空き容量が不足していないか確認します。
5. エラーメッセージや実行日時を記録します。
6. 問題が解決しない場合は、管理者または開発担当者へ連絡します。

自動バックアップが失敗した場合でも、レジ締めの結果が正常に保存されているかを確認したうえで、必要に応じて手動バックアップを実行してください。
